# HTTP Server in C++

It is a lightweight HTTP/1.1 web server built from scratch using C++20 and Winsock2, where I learn how web servers work internally without using any backend frameworks.

### What I Learn

* TCP socket programming and client-server communication.
* HTTP/1.1 protocol fundamentals.
* HTTP request and response structure.
* HTTP methods, headers, status codes and request bodies.
* Parsing raw HTTP requests.
* Generating HTTP responses.
* Socket creation, binding, listening and accepting connections.
* C++ pointers, references and memory management.
* Request routing and server-side request handling.
* Building backend infrastructure using raw C++.
